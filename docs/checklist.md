# Launch checklist

- [ ] Node.js and ffmpeg both print a version number (`npm run check`)
- [ ] escape-film folder created and @napi-rs/canvas installed (`npm install`)
- [ ] render.js in place, `node render.js` made film.mp4
- [ ] Changed one constant and saw only that thing change
- [ ] Rendered twice and got the same video (`npm run verify`)
- [ ] Added at least one PNG character (`hero.png`)
- [ ] Asked AI for your own scene with Prompt 1 (`prompts/01-new-scene.md`)
- [ ] Added voice and music, exported, posted. Tag @aiwithlakshay on Instagram
